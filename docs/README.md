# TaskMaster Documentation //////

Documentation for the TaskMaster project — a weight-based task management SaaS, self-hosted on a k3s home lab and delivered via ArgoCD.

## Contents

- **[Product Requirements Document (PRD)](./prd.md)** — product vision, personas, features, scope, and roadmap.
- **[Technical Specification](./technical-specification.md)** — tech stack, database schema, weight algorithm, API contracts, frontend architecture, and the k3s/ArgoCD deployment model.

## Related

- **Feature specs:** `.kiro/specs/` — per-feature requirements, design, and task breakdowns (auth-system, database-schema, and more added as features are built).
- **Steering:** `.kiro/steering/` — coding standards, project structure, and development environment conventions.

## Conventions

- Markdown with a clear heading hierarchy (H1 title, H2 sections).
- Code blocks include a language for syntax highlighting.
- Tables for structured comparisons; keep docs updated alongside code changes.
